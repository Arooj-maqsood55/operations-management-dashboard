# Operations Management Dashboard

MERN-based task workflows with status filtering and Python utilities for CSV validation/reporting.

**Timeline:** Eraviya Solutions — MERN Stack Developer (2024–2025)

## Stack

- React dashboard screens and forms
- Node.js / Express REST API
- MongoDB task records
- Python CSV validation helper

## Run

```bash
# API
cd server && npm install && npm start

# Client
cd client && npm install && npm start

# CSV checks
python3 scripts/validate_csv_import.py scripts/sample_tasks.csv
```
